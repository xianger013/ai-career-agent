# Resume Positioning

AI Career Agent can be described as:

> Built a full-stack AI career-planning workspace with FastAPI, Next.js, SQLite, an OpenAI-compatible LLM service, RAG-style profile retrieval, agent workflow orchestration, SSE progress streaming, and Markdown report generation.

## Resume Bullets

- Designed and implemented an AI agent workflow that converts job descriptions and profile notes into skill-gap analysis, learning phases, project recommendations, resume bullets, and interview Q&A.
- Built FastAPI services for job management, profile upload, fallback retrieval, optional embedding retrieval, and persisted Markdown analysis reports.
- Added a Next.js workspace with SSE step logs, profile evidence previews, Markdown rendering, copy actions, and report download.
- Added pytest coverage for health checks, text splitting, vector store behavior, embedding fallback, job analysis, and agent streaming.

## Short Pitch

AI Career Agent demonstrates end-to-end AI application engineering instead of only model prompting: persisted inputs, retrieved evidence, transparent workflow steps, structured outputs, tests, and public documentation.
