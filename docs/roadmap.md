# Roadmap

The roadmap keeps the project honest about its current scope while showing a credible maintenance path.

## Now

- Keep the fallback demo reliable without API keys.
- Maintain backend tests and frontend build checks.
- Keep public docs and screenshots in English.
- Track limitations clearly in README and release notes.

## Next

- Add Docker Compose for one-command local demos.
- Add a small retrieval evaluation fixture.
- Add hybrid keyword + vector retrieval.
- Add reranking experiments behind a feature flag.
- Add GitHub issue labels and release notes.

## Later

- Add authentication and user data isolation.
- Add a production vector-store adapter such as ChromaDB, FAISS, or pgvector.
- Add hosted demo deployment instructions.
- Add structured benchmark reports for retrieval and generated recommendations.
- Add maintainer automation for issue triage and PR review.
